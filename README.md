# mechkit

mechkit is a tool for designing and simulating mechanical systems for robotics,
machine design, and automation.

Its goals are to let users assemble parts and reusable mechanisms in a 3D
workspace, connect them, and explore how the resulting machines move and behave.
Simulation will support understanding motion, forces, loads, and required torque.

The interface should be concise, simple, and clear. The application will start on
macOS, with a Qt port planned later.

mechkit focuses on design and simulation; real motor control is outside its scope.
